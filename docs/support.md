# Support

Use the channel that matches your question so it reaches the right team.

| Topic | Channel |
|---|---|
| Account, transactions, product questions | [support@incrypto.me](mailto:support@incrypto.me) or the in-app chat at [incrypto.me](https://incrypto.me) |
| Business, partnerships, integrations, press | [hello@incrypto.me](mailto:hello@incrypto.me) |
| Security vulnerabilities | [security@incrypto.me](mailto:security@incrypto.me) — see the [disclosure policy](security/disclosure.md). Never report these publicly. |
| Errors or gaps in this documentation | [Open an issue](https://github.com/incryptohq/docs/issues/new/choose) in the docs repository |

Please do not share account details, transaction hashes tied to your identity, or any credentials in public issues.
